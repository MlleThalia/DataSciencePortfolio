# 🎯 Natural Language Processing

Ce projet réalise une inférence automatique entre deux phrases. Les modèles testés sont CamemBERT, CamemBERTa et LLaMA. Il exploite également la méthode LoRA pour le fine-tuning ainsi que différents modes d’apprentissage en contexte.

## 📂 Structure du projet

- `data/` — jeu de données
- `images/` — images
- `/.ipynb` - notebook d'expérimentations
- `/.pdf` - rapport
