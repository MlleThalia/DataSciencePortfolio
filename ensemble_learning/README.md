# 🎯 Méthodes ensemblistes

Ce projet vise à comparer les méthodes de bagging et de boosting sur plusieurs jeux de données.


## 📂 Structure du projet

- `datasets/` — jeux de données
- `docs/` — résultats et rapport
- `images/` — images
- `scripts/` — scripts Python
- `/` — notebooks d’expérimentation
