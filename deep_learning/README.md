# 🎯 Reconnaissance d'activités humaines avec un réseau de neurones MLP

Ce projet consiste à réaliser une classification visant à déterminer l’activité en cours d’un individu.

## 📂 Structure du projet

- `data/` — jeu de données
- `images/` — images
- `/.ipynb` — notebooks d'expérimentations
- `/.pdf` — rapport
